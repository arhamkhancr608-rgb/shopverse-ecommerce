
# 🛍️ ShopVerse — E-commerce Store

A modern, responsive e-commerce storefront built with HTML, CSS, and JavaScript.

## ✨ Features

- Responsive storefront design
- Product catalog with eight sample products
- Live product search
- Category filtering
- Interactive shopping bag counter
- Prices displayed in Indian Rupees (INR)
- Responsive layout for mobile and desktop

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/arhamkhancr608-rgb/shopverse-ecommerce.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or API key is required.

## 📌 Project Status

This is a portfolio project. The current version demonstrates
the frontend storefront and basic shopping bag interaction.
Backend integration, authentication, payments, and order
processing are not yet implemented.
